PÁGINA WEB INFORMATIVA CON NODE.JS Y EXPRESS - CON IMÁGENES

REQUISITOS:
- Tener instalado Node.js

COMANDOS PARA EJECUTAR:

1. Entrar a la carpeta del proyecto:
   cd web_instituto_don_bosco_express_img

2. Instalar dependencias:
   npm install

3. Ejecutar el servidor:
   npm start

4. Abrir en el navegador:
   http://localhost:3000

IMÁGENES:
Las imágenes están dentro de:
public/imagenes
